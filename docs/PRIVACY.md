# 隐私与上传检查

本仓库从已验收版本建立干净的源码快照。原开发提交包含私人邮箱及内部路径，因此没有推送原 Git 历史；发布提交使用 GitHub noreply 地址。

上传范围：应用源码、测试与三张不含身份信息的题目测试图、构建入口、无密钥配置示例、依赖版本和使用文档。EXE 通过 Releases 提供，不放入源码 Git 历史。

排除范围：个人 config.toml、所有 .env、Key、认证令牌、Cookie、浏览器登录资料、数据库、真实课堂图片与文档、课堂 URL/课程标识、内部交接、调试会话脚本、原始报告和日志、本地依赖、构建工作目录及备份。

上传前检查包括：原 Git 对象与作者元数据、导出文件敏感模式、当前配置 Key 的精确字节匹配、公开配置与示例一致性、测试图片人工查看、EXE 交付目录扫描及 ZIP 完整性检查。检查降低误传风险，不能证明不存在任何未识别的信息；如发现问题请停止分享并及时处理。

运行时，本地 OCR 离线；真实 AI 手动分析发送核对后的题目文本，自动原图核对还发送当前题图和 OCR 文本。目标服务由用户配置，不发送浏览器 Cookie 或 API Key 到题目内容中；Key 仅用于供应商 API 认证。

本地默认数据目录为 %LOCALAPPDATA%/RainClassAssistant；便携 EXE 免安装，但运行数据不会全部跟随 EXE 文件夹移动。退出登录不等于删除专用浏览器资料，删除缓存/历史不影响供应商账单。

报错反馈请只提供脱敏信息，勿附 Key、Cookie、个人配置、二维码、账号姓名、完整课堂链接、原始浏览器资料或数据库。
