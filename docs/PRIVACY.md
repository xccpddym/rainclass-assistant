# 隐私说明

这份文档说明三件事：仓库里有什么、软件在你电脑上存了什么、以及哪些内容会被发出去。

## 1. 仓库收录范围

**收录**：应用源码、测试代码与三张不含身份信息的题目测试图、构建脚本、无密钥的配置示例、依赖版本锁定、使用与开发文档。

**不收录**：个人 `config.toml`、`.env`、API Key、认证令牌、Cookie、浏览器登录资料、SQLite 数据库、真实课堂图片与文档、课堂链接与课程标识、内部交接记录、调试会话脚本、原始报告与日志、本地依赖、构建产物与备份。

仓库是从已验收版本建立的**脱敏快照**，不使用原开发历史。原提交包含个人邮箱与内部路径，因此没有推送；发布提交使用 GitHub noreply 地址。这么做是为了让仓库可以被安全地公开或分享，而不泄露开发者的身份信息与工作环境。

## 2. 你电脑上存了什么

默认目录 `%LOCALAPPDATA%\RainClassAssistant`：

| 路径 | 内容 |
| :--- | :--- |
| `real-readonly\` | 课堂设置、用量与历史数据库、诊断日志、提交防重记录 |
| `real-student\rainclass-edge-profile\` | 专用 Edge 资料目录，含登录 Cookie |
| `ui-preferences.json` | 提醒等界面偏好 |

题图在界面上显示，但**只保留在本次会话内存中**，不写入磁盘。

需要明确的一点：便携版指的是**程序免安装**，运行数据仍然留在上述用户目录。删除或移动 EXE 文件夹不会删除账号资料、历史或防重记录。

## 3. 会发出去的内容

### 本地 OCR（不联网）

题图在本地完成识别，模型随包提供。这一步不发送任何数据。

### 真实 AI（联网，由你触发）

| 场景 | 发送内容 |
| :--- | :--- |
| 手动 AI 分析 | 你核对后的题目文本（题型、题干、选项、填空数） |
| 自动原图核对 | 当前题图 + OCR 文本 |

- 发送目标是**你自己配置的服务地址**（默认 `https://api.deepseek.com`）。
- 不发送浏览器 Cookie，也不把 Key 混进题目内容里；Key 只用于向供应商 API 认证。
- 你关闭「启用真实 AI」后，不会发出任何 AI 请求。
- 数据到了供应商那一侧如何保留，取决于该供应商的隐私政策，本工具无法控制。

### 不发送的内容

账号密码、二维码、Cookie、浏览器历史、课堂链接、本地数据库、诊断日志——都不会作为题目内容外发。

## 4. 凭证处理

- Key 只从环境变量 `DEEPSEEK_API_KEY` 读取，配置文件里存的是**变量名**而非 Key。
- 软件不写日志记录 Key，也不把它显示在界面上。
- 发行包不含任何 Key、登录资料或题目历史。

如果你怀疑 Key 泄露：立即到供应商后台作废并重新生成，然后更新本机环境变量。

## 5. 反馈问题时

提交 Issue 或向他人求助时，**只提供脱敏信息**。请不要附带：

- API Key、任何形式的令牌；
- Cookie、浏览器资料目录压缩包；
- 个人配置文件；
- 登录二维码或账号姓名；
- 完整课堂链接或课程标识；
- 数据库文件、原始日志全文。

需要贴日志时，请先删掉链接、课程 ID、账号相关信息与任何疑似凭证的字符串。

## 6. 发布前的检查做了什么

历史发布前执行过的检查包括：

- 原 Git 对象与提交作者元数据扫描；
- 拟上传文件的敏感模式匹配（绝对路径、邮箱、令牌特征）；
- 当前配置中 Key 的精确字节比对；
- 公开配置与配置示例的一致性核对；
- 测试图片人工查看（无 EXIF、无身份信息）；
- EXE 交付目录全量扫描与解包后的应用代码复查；
- ZIP 完整性校验与 SHA-256 记录。

这些检查**降低**误传风险，但**不能证明**不存在任何未被识别的信息。如果你在仓库或发行包里发现了不该出现的内容，请立即提出，我们会尽快处理。

## 7. 合规提醒

本工具会读写雨课堂页面并可选地自动提交答案。请自行确认所在学校、课程与平台规则是否允许这类辅助。项目与雨课堂、DeepSeek 及其关联方没有官方隶属或背书关系。
