## 它解决什么问题

雨课堂的互动题通常是图片加短倒计时：题面看不清、来不及读、题型和空数还要自己数。这个工具用**独立 Edge 学生端**监测课堂，发现正式互动题后自动取题图、做本地 OCR、必要时让 AI 对照原图核对，然后把题干、选项、答案和解析摆在一个窗口里，可选地帮你填写并提交。

它不替代你的判断。默认是「先核对，再决定要不要用 AI」；自动作答需要你显式打开，随时可关。

## 一次题目从出现到你作答

```
课堂发布互动题
   │
   ├─ 独立 Edge 学生端监测到新题（区分普通 PPT 与正式习题）
   │
   ├─ 本地 OCR：题图 → 题型 / 题干 / 选项 / 空数      （离线，不联网）
   │
   ├─ AI 核对（可选）：原图 + OCR 文本 → 修正识别、给出答案与解析
   │
   └─ 作答：人工核对后填写，或按策略自动填写并提交
```

## 功能一览

| 能力 | 具体做什么 |
| :--- | :--- |
| 课堂监测 | 跟随新发布的正式互动题，普通 PPT 不当作题目；支持自动进入正在上课的课堂 |
| 题目识别 | 本地离线 OCR 提取题干、选项与填空数，题图与原图核对入口一并保留 |
| AI 分析 | 用 DeepSeek 对照原图修正 OCR，再生成答案、依据与解析 |
| 多题型 | 单选、多选、填空、文字主观题 |
| 作答控制 | 人工核对后作答；或自动核对 → 分析 → 填写 → 提交，主观题可逐题授权 |
| 异常保护 | 题目变化、题图变化、剩余时间不足、控件遮挡、答案映射异常时停止作答 |
| 提交去重 | 同一题不重复提交；提交结果未知时不自动重试 |
| 课堂提醒 | 新题弹窗、倒计时弹窗、主观题提示音，三个开关互相独立 |
| 设置记忆 | AI 开关、作答策略、预算、提醒、恢复设置重启后自动恢复 |
| 用量与预算 | 本地记录请求与用量，可选单课金额上限（0.1～10 元），不设请求次数上限 |

## 两种用法，选一种就够

**人工核对（默认，推荐先用这个）**
新题出现 → 看原图核对题型、题干、选项、空数 → 点「AI 分析」→ 按设置填写、提交。主观题在确认核对后可逐题选择「允许 AI 填写并提交本题」或「不用 AI，我手动答」。

**自动模式**
新题出现 → AI 对照原图核对 → 分析 → 填写 → 提交。主观题可以只填写、由你最后提交（关闭「填写后也提交」）。任何一步无法可靠完成都会停下来转人工，不会硬填。

## 快速开始

### 1. 下载与解压

从 [最新版本](https://github.com/xccpddym/rainclass-assistant/releases/latest) 下载 Windows x64 的 ZIP，**完整解压到一个普通可写文件夹**后运行 `RainClassAssistant.exe`。

- 需要 **Windows x64 + Microsoft Edge**，不需要安装 Python。
- `_internal` 文件夹、`config.toml` 和说明文件必须和 EXE 放在一起，不能只复制 EXE。
- 不要在压缩包里直接双击运行。同一台电脑只运行一个助手实例。

### 2. 配置 AI

在 Windows「编辑账户的环境变量 → 用户变量」中新增 `DEEPSEEK_API_KEY`，值为你自己的 Key，然后重新启动软件。

发行包附带的 `config.toml` 是不含密钥的公开模板，默认地址 `https://api.deepseek.com`、模型 `deepseek-flash`，Key 只从环境变量读取。已有同名环境变量可直接沿用；换电脑需要重新设置。

### 3. 登录课堂

在助手打开的**专用 Edge 窗口**里正常扫码登录学生账号并进入课堂。这个浏览器资料目录与你的日常 Edge 完全分开，不会读取日常登录状态。

### 4. 选好策略再开始

到「课堂设置 → 作答策略」选择人工核对或自动处理，按需勾选「启用真实 AI」「启用自动作答」。首次建议先用人工核对，确认当前课堂的识别和填写都正常，再开自动模式。

> AI 调用会产生供应商费用。金额预算可设为 0.1～10 元或关闭；真实课堂不设请求次数上限，关闭预算不代表免费。

## 想先试试？用本地模拟课堂

不登录真实课堂也能跑通全流程：在「本地模拟」页启动模拟教师端，在浏览器里发布题目、翻页，助手按同样的逻辑监测与作答。它只绑定本机回环地址，默认不调用真实 AI。

## 数据放在哪

运行数据默认在 `%LOCALAPPDATA%\RainClassAssistant`：

| 路径 | 内容 |
| :--- | :--- |
| `real-readonly\` | 真实课堂设置、用量与历史数据库、诊断日志、提交防重记录 |
| `real-student\rainclass-edge-profile\` | 专用 Edge 登录资料 |
| `ui-preferences.json` | 提醒等界面偏好 |

便携指的是软件免安装，**运行数据不会跟着 EXE 文件夹走**。删除或移动程序目录不会自动删除账号资料和历史。

## 边界与免责

- 已在 **Windows 11 x64** 本机实测；其他 Windows 版本、其他电脑、平台界面改版后均未验证。
- OCR 和 AI 都可能出错，填空数、题型、答案需要你自己核对；重要答案不要盲信。
- 自动原图核对会把**当前题图和题目文本**发送到你配置的 AI 服务；本地 OCR 全程离线。Key 只用于向供应商 API 认证。
- 锁屏、睡眠、断网、浏览器到前台等场景不保证可靠，详见[已知限制](docs/KNOWN_LIMITATIONS.md)。
- 请在**允许使用 AI 与自动化**的课堂、课程或测试环境中使用，并遵守学校与平台规定。
- 本项目与雨课堂、DeepSeek 及其关联方**没有官方隶属或背书关系**。
